Crop Yield Prediction

Capstone Project 2 Proposal Deck

Predicting agricultural yield using rainfall, pesticide usage, average temperature, crop type, area, and year from the merged dataset.

1. Executive Summary

This project aims to build a machine learning model that predicts crop yield for a given country, crop, and year using climate and agricultural indicators. The dataset contains 25,932 records and 7 core fields, making it well suited for supervised regression modeling. The expected outcome is a model that helps estimate future yield patterns and supports data-driven agricultural planning.

2. Problem Statement

Background

Crop productivity changes due to rainfall variation, pesticide usage, temperature shifts, geography, and crop type. Estimating yield manually is difficult because these factors interact in a non-linear way.

Objective

Train a regression model that predicts value_hg_ha, the crop yield value in hectograms per hectare, from environmental and agricultural features.

Scope

Use historical multi-country crop records and evaluate how rainfall, average temperature, pesticides, crop category, location, and year affect yield.

4. Methodology

Data Collection

Collect crop yield, rainfall, pesticide usage, and average temperature records from the provided Excel source files.

Data Preparation

Merging the datasets into one table and remove unnecessary columns

Clean missing values, align country and year fields, encode categorical columns such as area and item, and scale features if required.

Modeling

Train regression models such as Linear Regression, Random Forest, and XGBoost to predict value_hg_ha and compare performance.

Evaluation

Use MAE, RMSE, and R². Also analyze feature importance to understand which factors influence crop yield most.

5. Expected Outcomes

📈

Prediction Model

A trained regression model that estimates crop yield from climate and input variables.

🔍

Factor Insights

Identification of the most influential drivers, such as rainfall, temperature, crop type, and pesticides.

🌍

Decision Support

Practical recommendations for agriculture planning, crop management, and future productivity analysis.

6. Risks and Challenges

Yield patterns may vary greatly across countries and crops, which can increase model complexity.

Categorical variables like area and item require careful encoding and validation.

Historical records may contain outliers, measurement differences, or imbalance across years and crops.

Good model performance does not automatically imply strong real-world generalization, so validation is essential.

7. Conclusion

Crop Yield Prediction is a strong machine learning capstone topic because it combines agriculture, climate, and predictive analytics in a practical use case. The project is a supervised regression problem where the model predicts value_hg_ha. For this dataset, XGBoost or Random Forest Regressor is the best main algorithm choice, while deep learning can be mentioned as future scope rather than the primary method.
